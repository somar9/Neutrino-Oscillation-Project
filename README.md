# 3+1 Sterile-Neutrino Oscillation Analysis

A repository containing code, data, and scripts to reproduce the disappearance and appearance spectra in a 3-flavor and 3+1 sterile-neutrino framework, as presented in “Muon–Neutrino Disappearance and Search for Sterile Neutrinos using NOνA.”

---

## Overview

This project implements:
- 2-flavor, 3-flavor, and 3+1 sterile-neutrino oscillation probability calculations using [NuOscProbExact](https://github.com/mbustama/NuOscProbExact).  
- Near-Detector (ND) flux fitting and Far-Detector (FD) extrapolation.  
- Systematic uncertainty propagation via covariance matrices.  
- Multi-parameter fits (1→9 parameters) and goodness-of-fit metrics (χ², MAE, RMSE, Pearson r).  
- Scripts to reproduce all figures and tables from the dissertation.
